# HR Analytics Dashboard

## 📊 Project Overview

The HR Analytics Dashboard is a Power BI data analytics project designed to analyze employee information, workforce distribution, salaries, employee satisfaction, performance ratings and gender distribution.

The dashboard provides insights into employee headcount, salary distribution, departmental workforce, employee satisfaction, performance ratings and workforce distribution across different locations.

## 🎯 Project Objective

The objective of this project is to analyze HR data and identify patterns in employee distribution, salaries, satisfaction and performance across departments and locations.

The analysis is designed to help HR management understand workforce composition, compensation patterns and employee performance.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## 📁 Data Source

The analysis uses employee data containing information relating to:

- Employee names
- Departments
- Locations
- Salaries
- Gender
- Employee satisfaction
- Employee ratings

## 🧹 Data Preparation

The data was cleaned and transformed using Power Query.

Key data preparation activities included:

- Cleaning and standardizing data types
- Handling missing or incomplete values
- Standardizing categorical data
- Preparing employee and department information
- Preparing salary data for analysis
- Preparing satisfaction and rating data for visualization
- Creating calculated measures using DAX

## 📌 Key Performance Indicators

The dashboard tracks important HR KPIs including:

- Number of Staff
- Total Salary
- Average Salary
- Total Locations

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Employee headcount by location
- Employee headcount by department
- Salary by department
- Salary by location
- Individual employee salaries
- Employee satisfaction
- Department ratings
- Gender distribution
- Workforce distribution across locations

## 🔍 Key Insights

The analysis provides insights into workforce distribution, salary patterns, employee satisfaction and departmental performance.

The dashboard helps identify differences in employee numbers and salary distribution across departments and locations, while also providing an overview of employee satisfaction and performance ratings.

## 💡 Business Recommendations

Based on the analysis, HR management can use the dashboard to:

- Monitor workforce distribution across departments and locations
- Review salary distribution across departments
- Monitor employee satisfaction
- Track departmental performance ratings
- Understand workforce demographics
- Identify areas requiring further HR investigation
- Support data-driven workforce and compensation decisions
